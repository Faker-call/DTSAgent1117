# Proposal

## Why

核心 Agent 变更解决的是"结论是否正确"，但没有解决"能否长期稳定运行"：索引冷启动耗时长、长任务全程静默、并行扇出没有全局限流、审计可被改写、资源只增不减、模型变更没有灰度。这些不补，工具在团队里很难持续使用。

## What Changes

- 新增**健康自检**：一条命令检查配置、密钥、模型连通、索引完整性、锁状态、磁盘与沙箱。
- 新增**进度事件流**：长任务持续输出结构化进度，JSON 模式逐行输出。
- 新增**全局限流与配额**：进程级令牌桶、并发闸门、用户日/月配额。
- 新增**审计完整性**：哈希链记录与一键校验，篡改可定位。
- 新增**资源回收**：运行记录、工件与缓存按时间与容量双阈值回收。
- 新增**成本预估**：执行前预估 token 与费用，超阈值需显式确认。
- 新增**批量处理**：从文件批量读取待排查项并输出汇总。
- 新增**供应链检查**：依赖锁定、SBOM 生成、漏洞扫描入口。
- 新增**变更灰度**：模型或提示词按比例分流、指标对比、一键回退。
- 新增**多语言输出**：术语表驱动的中英文输出，结论内容不变。

明确不在本期范围：索引制品分发的服务端实现（依赖共享存储方案）、企业级监控平台对接（仅提供 OpenTelemetry 导出接口）。

## Capabilities

### New Capabilities

- `operability`: 运行期的可观测、可治理与可恢复能力：自检、进度、限流配额、审计完整性、资源回收、成本预估、批量、供应链、灰度与多语言。

### Modified Capabilities

无。本变更只新增能力，不修改既有契约；实现上依赖核心变更先行落地。

## Impact

- **前置依赖**：`add-render-engine-qa-diagnosis-agent` 需先实施，本变更复用其 CLI、审计、模型网关与索引模块。
- **新增代码**：`ops/` 包与 `M20 OpsGuard` 模块；对 CLI 增加 `doctor`、`audit` 子命令与 `--batch`、`--dry-run` 参数。
- **新增依赖**：SBOM 生成工具、漏洞扫描工具（可选）、多语言术语表文件。
- **运行影响**：所有命令增加一次配额与限流检查（毫秒级）；审计写入增加哈希计算（微秒级）。
- **风险**：配额误伤（计量故障导致误拦）、灰度期间指标不可比、多语言术语表维护成本。
