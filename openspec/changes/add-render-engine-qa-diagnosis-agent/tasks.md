# Tasks

## 实施前提

以下前提已在设计评审中确认：

- 真实引擎仓库尚未提供：首期用开源 `maplibre/maplibre-native`（固定 tag、`--depth 1` 浅克隆）作代码语料与定位靶场，`--repo` 可切换；实现逻辑不得绑定具体仓库。
- `compile_commands.json` 由 CMake 构建 maplibre-native 生成（至少一个 target）；缺失时 M05/M11 走语法级校验并标注降级。
- 历史工单为 JSON 格式且无真实数据：先合成 ≥60 条，字段与真实导出对齐，替换数据源不改摄取代码。
- 视觉结论为"描述 + 区域标注 + 人工确认"，不做自动缺陷定级。
- 数据合规：发往 DeepSeek 与百炼无需内部审批，脱敏作为技术措施保留。
- 模型接入：LLM 与视觉用 `deepseek-flash`（`DEEPSEEK_API_KEY`），embedding 用百炼 `qwen3.7-text-embedding`（`QWEN3.7`），保留 `offline` 开关。
- 权限：本期实现本地账号 + 四角色矩阵（管理员/维护者/开发者/观察者），单机多用户；企业 SSO 与多租户隔离不在本期。
- 多 Agent：星型拓扑，中心编排派发与汇总，子 Agent 间不通信；检索为"检索策略 Agent"，只检索不产结论。
- 长期记忆只在人工确认后写入，且只提供排序先验、不作为证据类别。
- 首期评测种子集 ≥ 60 条。
