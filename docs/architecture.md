# 架构

本文件描述代码结构与设计文档（`openspec/changes/add-render-engine-qa-diagnosis-agent/design.md`）中模块的对应关系。

## 目录结构

```
src/pmagent/
├── __init__.py           版本号
├── __main__.py           python -m pmagent 入口
├── errors.py             统一错误类型与退出码
├── contracts.py          跨模块数据契约（pydantic）
├── config.py             配置加载（默认值→文件→环境变量→命令行）
├── cli/                  命令行入口（M01）
│   └── main.py
├── orchestrator/         阶段流水线引擎（M02 骨架）
│   └── stage.py
├── store/                本地状态与追踪（M12）
│   ├── artifacts.py
│   └── trace.py
├── authz/                身份与权限（M16，待实现）
├── agents/               子 Agent（M09/M10/M15/M19，待实现）
├── knowledge/            索引与检索（M05/M06/M07，待实现）
├── evidence/             证据接入（M08，待实现）
├── memory/               记忆与恢复（M14，待实现）
└── gateway/              模型网关（M04，待实现）
```

## 分层与依赖

| 层 | 目录 | 允许依赖 |
|---|---|---|
| CLI | `cli/` | 所有层 |
| 编排 | `orchestrator/` | 领域层、知识层、证据层、网关 |
| 子 Agent | `agents/` | 知识层、证据层、网关 |
| 知识 | `knowledge/` | 存储 |
| 证据 | `evidence/` | 存储、外部工具 |
| 记忆 | `memory/` | 存储 |
| 网关 | `gateway/` | 外部 API |
| 存储 | `store/` | 无 |

依赖只能向下，禁止反向调用。

## 已实现（P0 骨架）

- **错误与退出码**（`errors.py`）：0/1/2/3/4/5/6/130。
- **数据契约**（`contracts.py`）：问题上下文、假设、定位报告、补丁工件、检索命中、文档记录、会话状态、运行事件、证据条目、案例、工具提案、成功信号、案例候选、用户、会话、授权裁决、进度快照、任务简报、子 Agent 结果、意图判定。
- **配置**（`config.py`）：四层优先级合并；密钥只读环境变量，`config show` 仅显示是否设置。
- **追踪与工件目录**（`store/`）：JSONL 追踪；`.pmagent/` 与 `artifacts/` 目录约定。
- **流水线引擎**（`orchestrator/`）：阶段重试、可选阶段降级、预算检查、状态机。
- **CLI 骨架**（`cli/`）：`--help`、`--version`、`config init/show`，其余命令占位。
- **模型网关**（`gateway/`）：DeepSeek 适配、角色映射与思考模式、重试退避熔断、结构化输出解析、成本核算、百炼向量化（批量/缓存/自适应限流）、密钥加载与抹除。
- **脱敏**（`evidence/redaction.py`）：坐标、设备标识、令牌、绝对路径的规则化替换与本地可逆映射，入库与出网双调用点。
- **身份与权限**（`authz/`）：SQLite 账号存储（argon2id）、12 小时会话令牌、四角色权限矩阵、策略引擎（阶段 × 子 Agent 工具白名单）、单写者文件锁。
- **代码索引**（`knowledge/index/`）：git 文件发现与过滤、tree-sitter 符号抽取与调用点、AST 切块、SQLite 存储（含 FTS5 全文表）、全量/增量构建、manifest 版本守卫、制品打包分发。
- **文档语料**（`knowledge/corpus/`）：markdown/html 适配器、标题层级切分（面包屑/表格整表/代码块独立）、JSON 工单清洗、FTS5 + 向量混合检索、版本权重；合成工单在 `data/tickets/synthetic_tickets.json`。
- **混合检索**（`knowledge/retrieval/`）：查询规划与标识符拆词、BM25/向量/符号图三路召回、RRF 融合与相邻合并、词法/交叉编码器重排、文件多样性约束、按意图调权。
- **记忆与恢复**（`memory/`）：四层记忆（L0 工作/ L1 会话 / L2 运行 / L3 案例）、证据账本与正文回取、四级压缩瀑布与事实回归、预算账本、事件日志与原子 checkpoint、结果缓存复用、成功信号与案例回流（留出集门禁 / 失效 / 反例）。
- **子 Agent**（`agents/`）：意图结构化特征与三态规则、否决项与模型仲裁、分级兜底、回答组装与引用校验、澄清策略、多轮意图漂移与回退；症状分诊、四源候选、代码切片、假设生成与评分、验证规划、定位报告与自洽性校验。
- **视觉与沙箱**（`evidence/vision.py`、`evidence/sandbox.py`）：截图规则检测（缝隙/纯色块/色带/错位）、可注入多模态描述与冲突标注、复现沙箱（容器优先、进程降级、`pmagent.yaml` 配置、环境差异标注）。
- **补丁建议**（`agents/patch.py`）：上下文收集、约束校验（单文件/不改头文件/行数上限）、静态检查降级标注、影响面分析、自审评分、工件存储与 `--yes` 应用/回滚。
- **多 Agent 编排**（`orchestrator/multiagent.py`）：子 Agent 运行时（角色白名单/预算/截止时间/契约校验）、中心派发与短路、并行扇出与失败隔离、共享证据账本、汇合去重与冲突检测、检索多轮补检、Critic 对抗评审、派发/贡献/加速比指标。
- **安全与治理**（`safety/`）：写路径白名单、注入检测与不可信数据包裹、命令模板化、唯一执行器与审计、不可跳过校验、进度快照与停滞/振荡/循环治理、硬上限、运行回放、离线降级。
- **评测**（`eval/`）：种子集导入与标注缺失统计、检索/定位/结论指标、报告对比与退化用例、置信度校准、双人标注一致性、人工评审回写、留出集门禁。
