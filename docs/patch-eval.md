# 补丁评测

## 设置

5 个夹具 diff：3 个应通过（最小修复、单行修复、并发修复），2 个应拒绝（4 文件越界、公共头文件）。
评估内容：约束校验、静态检查、自审评分。

## 结果

| 指标 | 数值 |
|---|---|
| 校验判定与预期一致率 | **1.000** |
| 校验通过率（3/5） | 0.600 |
| 编译检查状态 | 5/5 `skipped`（缺编译环境） |
| 编译通过率 | **null（无法测量）** |
| 人工接受率 | **null（无评审人）** |

## 说明

- 目标值是"编译通过率 ≥ 0.7、人工接受率 ≥ 0.4"，但本机没有 C++ 编译器与构建数据库，这两个指标**无法测量**；评测报告保留字段并显式置为 null，不伪造数字。
- 校验判定一致率 1.0 说明约束层能正确区分合法与越界改动。
- 自审评分对合法补丁均为 1.0、对越界补丁更低，符合预期。
- 接入真实构建环境与人工评审后，重新运行 `scripts/eval_patch.py` 即可得到真实指标。
