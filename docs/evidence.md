# 证据接入

## 支持的材料

| 材料 | 参数 | 处理 |
|---|---|---|
| 日志 | `--log`（可重复） | 正则归一化 + Drain3 模板聚类；保留原始行号；识别 ERROR/FATAL 等异常行 |
| 堆栈 | `--stack`（可重复） | 解析 `#N 0xADDR func at file:line`；有工具与二进制时符号化，否则保留原始帧并说明原因 |
| 崩溃 | `--crash` | minidump 解析头部与异常流（信号、故障地址、线程）；文本报告按关键字兜底 |
| 截图 | `--shot`（可重复） | 记录路径，视觉分析在第 11 组接入 |
| 复现工程 | `--repro` | 记录目录，沙箱运行在第 11 组接入 |

## 归一化

所有材料装配为 `ProblemContext`：

- 查询与工单文本先脱敏（坐标、设备标识、令牌、路径），规则命中写入 `redaction.rules_applied`；
- 日志只保留模板统计与异常行号，正文不进入上下文（需要时按路径重新读取）；
- 堆栈保留帧列表与符号化状态（`symbolicated` / `partial` / `unsupported`）。

## 充分性判定

| 意图 | 最小证据 | 缺失时行为 |
|---|---|---|
| 缺陷排查 | 日志 / 堆栈 / 崩溃 / 复现 / 截图（任一项） | 列出材料清单，退出码 3 |
| 定位请求 | 带文件行号的堆栈或明确代码位置 | 额外要求位置信息 |
| 用法/概念 | 无 | 不阻塞 |

版本与平台缺失时会额外请求补充，用于过滤版本相关知识。

## 实测

| 场景 | 结果 |
|---|---|
| 十万行日志分析 | 1.6 秒；聚成 2 个模板；识别 100 行异常；保留首末时间戳 |
| 日志模板 | 时间戳、十六进制、坐标、路径、线程号、数字均被掩码后再聚类 |
| 堆栈解析 | `#N 0xADDR func at file:line` 格式可解析；无工具/无二进制时 `unsupported` |

## 符号化降级说明

`llvm-symbolizer` 与 `addr2line` 都不在本机 PATH 中，也没有引擎二进制，因此当前实际运行时
`symbolication_status` 为 `unsupported`，报告中保留原始地址并给出降级原因。测试用注入的
`runner` 覆盖了成功路径，接入真实构建产物后无需改代码。
